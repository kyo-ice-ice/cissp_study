# CISSP 演習帳 — iPhone のホーム画面に置く手順

## なぜホスティングが必要か

iOS の Safari には、ローカルファイルを開く機能がありません（アドレスバーに `file://` を入れても動きません）。
Edge や Chrome が候補に出るのは、それらが自前のファイル閲覧機能を内蔵しているからです。

さらに「ホーム画面に追加」は Safari 専用の機能で、かつ URL を持つページにしか使えません。
つまりローカルファイルのままでは、どのブラウザを使ってもアプリ化はできません。

**どこかの URL に置く。それだけで全部解決します。**

---

## このフォルダの中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（705 KB・これ 1 つで完結） |
| `sw.js` | オフライン動作用。初回アクセス後は電波がなくても起動します |
| `manifest.webmanifest` | アプリ名とアイコンの定義（Android / PC 用） |

3 つとも**同じ階層**に置いてください。`sw.js` が別階層だと動きません。

---

## 手順 A：GitHub Pages（推奨・無料）

1. GitHub で新しいリポジトリを作る（例：`cissp`）
2. **Add file → Upload files** で上の 3 ファイルをまとめてドラッグ＆ドロップ → Commit
3. **Settings → Pages** を開く
4. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
5. 1〜2 分待つと `https://<ユーザー名>.github.io/cissp/` が発行される

### 注意：無料プランでは公開リポジトリが必要です

GitHub Pages は、無料プランでは公開リポジトリのみ対応です。非公開リポジトリから公開するには
GitHub Pro 以上が必要です。

ただし**どちらの場合も、発行されたサイト自体は誰でも閲覧できます**
（サイトへのアクセス制限は Enterprise Cloud の機能）。
中身は CISSP の学習教材なので実害は薄いはずですが、社内資料由来の記述が含まれないかだけ
一度確認しておくと安心です。気になる場合は下の手順 B を使ってください。

---

## 手順 B：URL を公開したくない場合

- **Cloudflare Pages / Netlify** — 無料枠でパスワード保護やアクセス制限をかけられます
- **社内・自宅のサーバー** — HTTPS であれば何でも構いません

Service Worker は **HTTPS または localhost でのみ動作**します。素の HTTP だとオフライン機能が無効になります
（アプリ自体は動きます）。

---

## 手順 C：iPhone のホーム画面に追加

1. **Safari** で発行された URL を開く
2. 下部中央の**共有ボタン**（□に↑）をタップ
3. 少しスクロールして **「ホーム画面に追加」**
4. 名前を確認して「追加」

これで全画面のアプリとして起動し、2 回目以降は電波がなくても開きます。

> **Safari で開くこと。** Chrome や Edge から追加すると、ただのブックマークになり全画面になりません。

---

## 進捗データについて

- 進捗は**その端末のブラウザ内**に保存されます。サーバーには一切送信されません
- したがって iPhone と PC で進捗は共有されません
- Safari は**長期間開かないサイトのデータを自動削除する**ことがあります

**設定画面 →「バックアップを書き出す」** で JSON を保存できます。
月に一度ほど書き出して iCloud Drive に置いておくと安全です。復元は同じ画面の「読み込む」から。

現在の保存方式は、設定画面の一番下（「この教材について」）で確認できます。
`この端末のブラウザ内（localStorage）` と表示されていれば正常です。
`メモリのみ` と出ている場合は保存されないので、ホスティング経由で開き直してください。

---

## アプリを更新したいとき

`index.html` を差し替えてアップロードするだけです。
Service Worker は**次に開いたとき**に新しい版へ切り替わります（1 回目は旧版のまま起動し、
裏で新版を取得します）。すぐ反映したい場合は 2 回開き直してください。

---

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 全画面にならない | Safari 以外から追加している。Safari でやり直す |
| オフラインで開けない | `sw.js` が同じ階層にない、または HTTP で配信している |
| 進捗が毎回消える | 設定画面下部の保存方式を確認。`メモリのみ` なら URL 経由で開き直す |
| 404 が出る | Pages の反映に 1〜2 分かかる。`Settings → Pages` の緑のチェックを待つ |
